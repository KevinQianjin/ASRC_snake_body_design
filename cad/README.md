# CAD sources and previews

[Project home](../README.md) · [Current design](../docs/current_design.md)

- [U module STEP](modules/UniDirectional_96.step) and [M module STEP](modules/Medium_Stiffness_96.step): original 96 mm module geometry.
- [Tank STEP](tank/tank-v2.step) and [reference images](tank/reference_images/): source geometry for tank screening.
- [U4+M2 viewing package](previews/u4m2/README.md): SCAD assembly and its companion STL files. Keep those files together.

- [500 g simulation reference](simulation_reference/u4m2_500g/README.md): exact solver parameters, tendon coordinates and rotatable reference views; physical routing and installation conflicts are explicitly recorded. This is not a manufacturing release.

The viewing package does not establish M-backbone integration, module connections or tendon continuity. The [superseded prototype](../archive/superseded_cad/full_length/NOT_THE_SIMULATED_DESIGN.md) is archived separately and must not be mistaken for the simulated design.
