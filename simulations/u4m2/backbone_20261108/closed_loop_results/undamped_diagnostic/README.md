# Undamped controller diagnostic

This is an incomplete initial run (551 reference samples). At sample 432, measured angular error grew after an applied correction. Near large yaw, the fixed nominal gain produced failed settled angle checks. These archived results motivated the output-based damping rule; they are not the final controller results. The unchanged prefix before sample 432 was retained when evaluating the updated controller. No perturbation parameters are supplied to the damping rule.
