# Historical studies and superseded files

[Project home](../README.md) · [Current simulations](../simulations/README.md) · [Path map](../docs/repository_map.md)

These folders preserve earlier work and its original inputs/results. Their assumptions differ from the active U4+M2 model.

- [Four-rope inverse study](legacy_studies/four_rope_inverse_5_to_11/README.md): 5–11 front-module configurations.
- [Front module count sweep](legacy_studies/front_sweep_5_to_11/README_front_sweep.md): earlier passive front/rear screening.
- [Reach extension study](legacy_studies/reach_extension/results/README.md): source and saved results now share one folder.
- [Superseded full-length CAD](superseded_cad/full_length/NOT_THE_SIMULATED_DESIGN.md): not the simulated continuous 96 mm design; retain the [cleanup review](superseded_cad/full_length/CLEANUP_REVIEW_CONFIRMATION.md).
- [Tendon-joint demonstration](superseded_cad/tendon_joint_prototype.scad): historical concept, not a validated interface for the active design.
- [Upload utilities](utilities/): historical machine-specific helper scripts. Their original contents are retained; use the project's normal Git workflow for current work.
